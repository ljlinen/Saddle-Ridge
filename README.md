# Saddle Ridge Equestrian Centre
Run: `npm install && npm run dev`  |  Build: `npm run build`

## Where to change things
- Text, links, services, reviews, contact details, image file names: `src/data/site.js`
- Images: drop files into `public/images/` (names are listed in `site.js`)
- Markup per section: `src/components/`
- Colors, fonts, spacing variables: top of `src/styles/base.css`
- Section styles: `src/styles/<section>.css`; breakpoints: `src/styles/responsive.css`
- Scroll and animation logic: `src/hooks/`
